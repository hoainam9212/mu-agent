# VAR Bàn Phím

Bàn phím Android cho fan MU người Việt: khi MU thủng lưới hoặc nhận thẻ đỏ, VAR giữ lại câu chửi người
bạn đang gõ (chê chuyên môn thì cho qua), sáng mai trả lại để bạn chọn Gửi / Viết lại / Bỏ,
và rủ anh em "vào hang" thay vì réo trọng tài.

- Kế hoạch triển khai MVP: [docs/PLAN.md](docs/PLAN.md)
